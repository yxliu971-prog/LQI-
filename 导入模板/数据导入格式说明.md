# LQI 数据导入格式说明

## 1. 先复制模板，再填写自己的数据

项目和便携程序的根目录都提供 `导入模板` 文件夹：

- `LQI_数据导入模板.xlsx`：推荐使用。包含“填写数据”“格式示例”“填写说明”三个工作表。自己的实验数据填写在“填写数据”中。
- `LQI_数据导入模板.csv`：UTF-8 编码的空白模板，只有列名，填写数据后再导入。
- `LQI_填写示例_12条.csv`：12 条公开溶解度数据，只用于查看正确格式或体验导入。
- `导入格式说明.html`：可双击打开的填写说明。

保留原模板，另存为自己的实验文件。空白模板没有实验记录，直接导入会提示“文件中没有数据行”，需要先填写。

## 2. 每列怎么填写

第一行必须是列名，从第二行开始每行一条观测。不要在表格上方加大标题或说明。

| 模板列名 | 是否必填 | 填写内容 |
|---|---|---|
| 样品编号 | 推荐 | 例如 S001。作为记录标识，不作为模型特征。 |
| smiles（分子线性编码） | 必填 | 有效的分子结构编码，例如 `CCO`。不是分子名称、CAS 编号或图片。 |
| target（目标实测值） | 训练必填 | 真实测量的数值。可改名为“溶解度（mg/mL）”“收率（%）”或“带隙（eV）”。 |
| 温度（℃） | 可选 | 纯数值，例如 `25`。没有测量或不需要时留空，或删除整列。 |
| 时间（h） | 可选 | 纯数值，例如 `2`。整列使用小时，不要混入分钟。 |
| 浓度（mol/L） | 可选 | 纯数值，例如 `0.1`。整列使用同一单位。 |

最简文件只需结构列和一个目标数值列。列名可以修改，列顺序可以变化；导入后必须确认软件选择了正确的结构列和目标列。模板中的英文列名都附有中文说明。

## 3. 数值与单位规则

- 单元格填写纯数值。单位放在列名中：填 `25`，不要填 `25℃`；填 `0.1`，不要填 `0.1 mol/L`。
- 如果收率列以 `%` 为单位，82.5% 的收率填写 **82.5**。不要把单元格设置成 Excel 百分比格式，否则存储值可能是 0.825。整列也可以统一采用 0～1 的比例，但必须明确列名和含义，不能混用两种尺度。
- 溶解度原值、溶解度对数和不同浓度单位不能混用。示例中的 target 是 **logS，即 mol/L 溶解度的十进对数**，因此允许出现负数；它不是 mg/mL 溶解度。
- 缺失值留空，不要用 0、横线、“未测”或“无”代替。0 是一个真实数值。
- 均值/中位数填充针对特征，不能用来补齐缺失的目标标签。缺失目标记录不能参与模型训练。
- 公式计算结果在导入前先“复制 → 选择性粘贴为数值”。不要依赖未保存的公式计算结果。
- SMILES 和样品编号按文本保存，避免 Excel 自动转成日期或科学计数法。

## 4. 文件和数据量要求

- Excel 使用 `.xlsx`，CSV 使用逗号分隔并保存为 UTF-8；推荐 Excel 的“CSV UTF-8（逗号分隔）”格式。`.xls`、图片和 PDF 不能直接导入。
- Excel 导入时选择“填写数据”工作表。不要把“填写说明”工作表当作实验数据导入。若体验参考数据，可选择“格式示例”。
- 不要合并单元格，不要设置重复列名或空列名，不要添加合计、平均值或文字说明行。
- 保持每列一种含义、每行一条完整观测。平行实验可以分别成行，保留独立编号；同一分子会被放在同一交叉验证组。
- 训练至少需要 **10 条有效观测和 6 种不同分子**，目标不能全部相同。少量记录可以用于查看导入格式，但不足以训练。推荐先用少于 100 条数据。
- 多个目标属性可以放在不同列，但一次训练只选择一个目标。不要把其他目标或由目标计算出来的量误选成特征。

## 5. 在软件中如何导入

1. 进入“数据与预处理”，点击“导入 CSV / Excel”。
2. 选择填写好的文件；如果是 Excel，选择相应的数据工作表。
3. 在结构列下拉框中选择 `smiles（分子线性编码）`，在目标列下拉框中选择 `target（目标实测值）` 或自己重命名的属性列。
4. 检查红色结构错误和黄色目标缺失提示，修正数据后再训练。软件会自动识别列，但不能代替人工确认。
5. 如果需要让模型使用温度、时间、浓度，在附加数值特征列表中勾选这些列；不用的列不勾选。样品编号不应作为特征。
6. 在“模型与解释”中选择模型和预处理方法，然后开始训练。

训练使用了附加条件时，新分子预测也需要提供对应字段。例如，附加条件输入框可填写：

```json
{"温度（℃）":25,"时间（h）":2,"浓度（mol/L）":0.1}
```

字段名必须与训练时勾选的列名一致，只提供实际使用的条件。没有附加条件时留空。

## 6. 示例数据与适用范围

“格式示例”和示例 CSV 来自随软件附带的 `examples/solubility_60.csv` 前 12 条记录，目标值是 ESOL 水溶解度 logS。为了不编造实验条件，温度、时间、浓度留空。样品编号是为了展示表格格式增加的记录标识。

来源：[Delaney / ESOL 数据快照](https://raw.githubusercontent.com/deepchem/deepchem/master/datasets/delaney-processed.csv)，详细出处见 [DATA_SOURCES.md](../docs/DATA_SOURCES.md)。正式分析时请使用自己的实测数据，勿把这些演示记录混入自己的实验表。

未知目标的新分子应在训练后进入“新分子预测”页面输入，不需要为了导入而编造目标值。当前软件按每行一个分子编码处理，不支持直接把反应方程式或 reaction SMILES（反应分子编码）作为普通 SMILES 输入。
