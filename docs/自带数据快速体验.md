# LQI自带数据快速体验

不需要准备文件，也不需要联网。按下面步骤操作，即可完整体验一次“导入 → 训练 → 看图 → 预测 → 导出”。软件右上角的“使用说明”按钮也能查看本说明。

## 1. 打开软件，加载示例

双击 项目根目录的 `start.bat`，进入“数据与预处理”，点击 **“加载溶解度示例 · 60 条”**。

看到“数据记录 60、有效结构 60、待处理行 0”即可。分子结构列选择 **smiles（分子线性编码）**；目标属性列选择 **logS (mol/L)（摩尔每升溶解度的十进对数）**。软件会自动选好。

这个示例来自内置水溶解度参考集，任务是：根据分子结构，估计它在水中的溶解度。目标是十进对数，数值越大，通常表示越容易溶于水。

## 2. 保持默认设置，训练一次

点击左侧 **“模型与解释”**，保持以下设置：

| 设置 | 选择 |
|---|---|
| 分子特征 | 化学描述符 · 24 个 |
| 回归模型 | Ridge（岭回归） |
| 缺失处理 | 中位数填充（特征） |
| 数据缩放 | StandardScaler（标准化缩放） |
| Bootstrap（自助重采样）次数 | 60 |

点击 **“开始训练与交叉验证 →”**，等待底部提示训练完成。首次启动可能稍慢，训练过程中不要关闭程序。

这组示例的结果约为：**R2（决定系数）0.856、MAE（平均绝对误差）0.683、RMSE（均方根误差）0.902**。这只是示例表现，不代表其他实验数据也有同样效果。

看结果时先记住两点：决定系数通常越接近 1 越好；两种误差通常越小越好。向下滚动，还能看到观测值与预测值散点，以及 **SHAP（沙普利特征贡献）** 前五项。

## 3. 看分子处于什么化学空间

点击 **“化学空间”**，保留内置 **Delaney（德莱尼）/ ESOL（水溶解度数据集）** 和 **PCA（主成分分析）**，点击 **“生成联合化学空间 →”**。

紫色点为你的 60 条示例，浅灰紫色点为参考分子，玫紫色点表示低相似度区域。鼠标停在点上可看分子结构；滚轮缩放，拖动平移，双击复位。

本示例本来就抽自参考集，因此“低相似度 0 个”是正常结果。要体验另一种图，可以选 **t-SNE（分布随机邻域嵌入）** 后重新生成。

## 4. 预测一个新分子

点击 **“新分子预测”**，在第一行粘贴以下编码：

```text
CC(=O)Oc1ccccc1C(=O)O
```

第二行的附加特征留空，点击 **“预测分子属性 →”**。使用上面的默认训练设置，预测值约为 **−1.858**，模型均值区间约为 **[−2.286, −1.347]**。

界面还会显示分子结构，以及最相似的 3 个参考分子。区间只反映模型的不确定性，不能当作未来单次实验结果的保证范围。

## 5. 导出这次体验

点击 **“诊断报告”**，选择 **“导出 PDF（便携文档格式）报告”** 或 **“导出 HTML（网页格式）报告”**，保存到自己容易找到的位置。

报告会整合训练指标、特征贡献、刚生成的化学空间和最后一次预测。若想保存原表格和设置，点击顶部 **“保存项目”**；下次打开项目后需要重新训练。

**第一次体验只用默认设置即可，不必先在线更新数据，也不必安装任何环境。**

## 导入自己的数据

体验完成后，可复制软件根目录“导入模板”中的 Excel 或 CSV 模板填写自己的实验数据。第一行是列名，每行一条观测。具体格式见 [数据导入格式说明](数据导入格式说明.md)，或打开模板文件夹中的“导入格式说明.html”。
