# LQI 软件设计说明书

版本 1.0.0，2026-10-01。本文描述当前交付实现，可作为后续维护和软件材料编写基础。

## 一、设计目标与范围

提供免 Python 环境配置的 Windows 分子属性回归应用。以少于 100 条的实验数据为主要使用场景，统一提供清洗、分子特征、交叉验证、解释、参考空间、预测与报告。所有实验数据在本地处理。

当前实现对象是单分子 SMILES 与连续标量目标，不包含反应路线规划、量子化学计算、模型服务端部署或云账号系统。

## 二、模块结构

| 模块 | 职责与接口 |
|---|---|
| main.py | 多进程冻结支持、应用初始化、日志、异常展示、主窗口 |
| chemistry.py | RDKit SMILES 解析与缓存、canonical 标识、24 描述符、Morgan 指纹、二维图像、Tanimoto 近邻 |
| data.py | CSV/Excel 读取、列识别、逐行校验、参考集 JSON 目录与快照更新 |
| engine.py | TrainingConfig、清洗、折内流水线、嵌套 GroupKFold、GridSearchCV、Bootstrap、SHAP、单分子预测 |
| space.py | 指纹联合矩阵、PCA/t-SNE、参考集相似度和覆盖标记 |
| plots.py | Qt 原生散点绘制、分子富文本悬停、缩放平移 |
| reports.py | Matplotlib 离线图像、HTML/PDF 报告、CSV/JSON 分析数据 |
| ui.py | 中文主窗口、五页工作流程、编辑及失效管理、后台 Worker 信号通信 |
| diagnostics.py | 独立发布包内置自检：全部模型、Excel、降维、报告、Qt 窗口 |

GUI 使用 PySide6 Essentials 与 QPainter，不依赖 Chromium 或 WebEngine。报告图像使用 Matplotlib Agg 后端，分子图使用 RDKit Draw。

## 三、数据流与状态

导入表格 → 识别并确认列 → RDKit 结构校验 → 选择特征与算法 → 准备有效观测 → 嵌套分组交叉验证 → 全量调参拟合 → 分组 Bootstrap → SHAP → 可视化与报告。

原始表格保留在 DataFrame，非法记录只在清洗阶段按明确策略排除，原始表格不静默删改。审计记录输入/使用/剔除数量、不同分子数、特征数、有效源行号。

状态包含当前表格、训练配置、拟合结果、化学空间结果和最近预测。数据或训练配置变化清空拟合与预测；数据/参考集/降维参数变化清空空间；预测输入变化清空旧预测。报告读取当前有效结果，避免混用历史状态。

项目采用 JSON 格式 `lqi-project-1`，包含表格的 split 表示、数据名称与训练配置；不使用外部模型 pickle 反序列化。

## 四、算法设计

### 分子特征

描述符面板：MolWt、MolLogP、TPSA、NumHDonors、NumHAcceptors、NumRotatableBonds、RingCount、NumAromaticRings、NumAliphaticRings、FractionCSP3、HeavyAtomCount、NHOHCount、NOCount、NumHeteroatoms、MolMR、LabuteASA、BertzCT、BalabanJ、HallKierAlpha、Kappa1/2/3、MaxPartialCharge、MinPartialCharge。

Morgan radius=2，fpSize=2048。非有限描述符转换为缺失值。额外数值列需明确勾选，目标与结构列禁止作为附加特征。

### 验证与调参

canonical SMILES 为组标识；5 折外层 GroupKFold；每个外层训练集内使用最多 5 折 GroupKFold 执行 GridSearchCV。预处理由 sklearn Pipeline 封装 SimpleImputer、Scaler、Regressor，训练折独立拟合。网格搜索优化负 MAE。

所有外层测试预测拼接为 OOF，计算 R²、MAE 和 RMSE。之后在全部有效数据上再次进行分组网格搜索并拟合最终模型。线性/树模型均固定随机种子和单线程配置，使结果便于复现。

### 不确定性与解释

以不同分子为采样单位，有放回抽样；每个被选中分子的全部观测一起保留。按最佳参数克隆整条 Pipeline 并重新拟合，预测分布的 2.5% 与 97.5% 分位数作为模型均值区间。

线性模型使用 SHAP LinearExplainer，树模型使用 TreeExplainer。解释的是经过拟合填充和缩放后的模型输入；平均绝对 SHAP 排序输出前五。没有用内置 feature_importances_ 冒充 SHAP。

### 化学空间

联合参考与用户 Morgan 矩阵进行 PCA；t-SNE 前以最多 30 维 PCA 降噪，perplexity 根据数据数量调整。固定种子 42。每个用户分子计算与全部参考分子的最大 Tanimoto，低于阈值标记为低覆盖。该判定独立于降维坐标。

## 五、交互、异常与本地存储

耗时训练、参考更新、映射、预测和报告导出通过 QThread Worker 运行。进度与完成结果由 Qt signals 回到主线程，绘图和控件更新不跨线程进行。运行时锁定分析控件，允许页面切换；关闭需等待任务结束。

公开集目录为 JSON，数据快照为 CSV。在线更新有超时、10 MB 大小限制、必需列校验与 SMILES 有效率校验。新数据写入内容哈希命名文件，随后原子替换目录文件；失败保留旧目录与离线数据。

用户错误以中文提示；异常堆栈写入本地日志。源码版与发布版均将用户目录、日志置于各自运行根目录。

## 六、报告与可复核性

HTML 内嵌 PNG，PDF 使用 ReportLab 中文 CID 字体与离线图像。报告包含配置、指标、最佳参数、数据清洗统计、特征解释、可选空间与预测、方法边界。CSV 记录 OOF 源行、真值、预测和残差；JSON 记录折划分组信息与审计。

## 七、部署与后续边界

使用 PyInstaller onedir Windows x64 发布，包含解释器、RDKit 和必要动态库。Qt 与第三方库保持独立文件，发布时保留许可证与来源声明。代码模块化组织，后续可扩展校准预测区间、骨架/时间划分、反应指纹、更多公开数据适配器及正式安装程序。
