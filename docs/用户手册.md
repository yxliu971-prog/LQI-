# LQI 用户手册

版本：1.0.0　运行环境：Windows x64　界面语言：中文

## 1. 启动与工作流程

源码版先运行 `setup.bat` 安装依赖，再双击项目中的 `start.bat`；便携版直接启动发布文件夹里的 `LQI.exe`。左侧依次为数据、模型、化学空间、预测和报告。导入后先确认列映射，再进行训练。耗时计算在后台线程中运行，底部显示处理阶段。

## 2. 导入和修正实验表

首次导入自己的数据，先复制软件文件夹中 `导入模板/LQI_数据导入模板.xlsx` 或 CSV 模板填写。Excel 选择“填写数据”工作表。每列的填写要求、单位规则和操作步骤见 [数据导入格式说明](数据导入格式说明.md)。

至少需要一个 SMILES 列与一个数值目标列。CSV 支持 UTF-8 与 GB18030，Excel 支持 `.xlsx` 并可选工作表。程序自动推断结构列和目标列，但应人工核对。

红色行表示结构空白或 RDKit 无法解析；黄色行表示目标缺失、无穷大或不能转换成数值。双击单元格可修正。修改会清除以前的模型、空间与预测结果，保证新报告对应当前数据。

SMILES 不支持省略成中文分子名称。诸如 `CCO`、`c1ccccc1` 是有效例子；`ethanol` 不是结构编码。目标必须采用一致单位。

点击“导出当前表格”可保存修正后的 CSV/Excel。源文件不会自动被覆盖。

## 3. 训练模型

选择分子特征、模型、缺失策略和标准化方法。初次尝试可使用默认 Ridge + 24 描述符 + StandardScaler。Morgan 指纹提供 2,048 个二值特征。附加数值特征须主动勾选，例如温度、时间、浓度；不要选择已经由目标推导的值。

均值/中位数只用于特征，不填充缺失标签。选择删除时排除特征含缺失的行。非法结构默认阻止训练；勾选排除后会在审计中记录数量。

至少需要 10 条有效观测、6 种不同分子。模型使用 5 折外层分组交叉验证；每个外层训练集内部继续做最多 5 折网格搜索。内层评分按 MAE，最终显示所有折外预测汇总的 R²、MAE、RMSE。R² 可能为负，表示模型不如简单基准，不代表程序错误。

调参候选：Ridge alpha 0.1/1/10/100；Lasso alpha 0.001/0.01/0.1/1；Random Forest max_depth 3/无限、min_samples_leaf 1/3；LightGBM num_leaves 3/7、reg_lambda 1/10；XGBoost max_depth 2/3、reg_lambda 1/10。树模型均为 100 棵树，提升模型学习率 0.05。

SHAP 面板显示平均绝对贡献前五项。数值越大代表对该模型输出影响越大，并不说明正负方向或因果性。完整记录可从报告页导出。

部分 Lasso 候选在高相关特征、小样本下可能在迭代上限内未收敛。软件收集拟合与数值警告，在训练面板提示并写入报告/JSON。警告可能来自交叉验证候选或 Bootstrap，并不一定来自最终选中的模型；仍应谨慎解释，可改用 Ridge 或精简特征。训练完成不等于模型已获得实验验证。

## 4. 参考数据与化学空间

默认参考集为 ESOL。无需网络即可使用。点击“在线更新 ESOL”主动下载最新上游快照；失败保留本地版本。添加参考集需选择本地表格及结构/属性列，数据不得含无效结构或目标缺失。

PCA 适合观察全局趋势，t-SNE 适合探索局部分布；后者距离和聚类形状不等于严格的化学距离。散点为用户数据（紫色）、参考数据（浅灰紫色）、低相似度用户分子（玫紫色）。

悬停查看二维结构和数值；鼠标滚轮缩放，左键拖动平移，双击还原。新颖性由用户分子与当前参考集中最相似分子的 Morgan Tanimoto 分数判断，低于可调阈值则标玫紫色。

示例数据抽自 ESOL，因此在 ESOL 中会找到自身，分数为 1.0。软件不排除这种完全重叠，并如实展示覆盖结果。

## 5. 新分子预测

完成训练后输入有效 SMILES。如果训练中选择了附加特征，必须填写对应 JSON 对象，例如 `{"温度":80,"时间":2}`。不提供条件时程序会提示缺少哪些字段。

预测卡片包含估计值和 95% Bootstrap 模型均值区间。默认 60 次按分子重采样，可在训练设置调整到 20–300 次。区间不含完整实验噪声，不是实验结果保证范围。

下面列出参考集中最相似的 3 个分子、结构图、属性与相似度。若用户预测目标为收率而参考集为 logS，两者不是同一属性，勿直接比较其数值。

## 6. 保存和导出

顶部“保存项目”将当前数据与训练设置保存为 JSON；“打开项目”恢复配置。模型对象不写入项目，重新打开需重训。HTML/PDF 报告保留已完成的结果，适合分享和复核。

报告页：HTML 包含内嵌图片，不依赖互联网；PDF 包含中文文字与分析图；分析表格目录包含 Top 5 特征、逐行折外预测、化学空间（若已计算）、审计 JSON。最后一次有效新分子预测会加入报告。

## 7. 常见问题

**程序不能启动：** 保持发布目录完整，不能只移动 EXE。查看 EXE 旁 `logs/lqi.log`。源码开发使用 `.venv/Scripts/python.exe main.py`。

**训练拒绝执行：** 检查非法 SMILES、目标列、有效观测和不同分子数量。全部目标相同也不能进行有意义的回归评估。

**图为空：** 先导入数据，再计算；更改数据、参考集或降维设置会使旧图失效，需要重新计算。

**区间太宽：** 可能是样本不足、模型不稳定或数据覆盖较差。它提示需要补实验，不应单纯通过降低重采样次数让区间看起来更窄。

**报告按钮提示无结果：** 数据或训练参数有变更时需重训。程序主动清除失效结果，防止报告与配置不一致。

**想分析催化反应：** 可导入选定分子编码、收率与实验条件进行初步回归。本版本未实现多反应物反应指纹和机理推断，需自行明确每行的化学含义。
